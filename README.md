# Analytics Report & Insights Documentation

## Project overview
A beginner-friendly data analytics portfolio project that demonstrates business-question framing, data-quality checks, KPI calculation, trend analysis, visualizations, business insights, and recommendations.

**Important:** `ecommerce_sales_sample.csv` is a synthetic sample dataset created for practice. It is not real company/customer data. Treat the numerical findings as demonstration results, not claims about a real business.

## Business objective
Evaluate sales performance across months, product categories, regions, and sales channels. Identify where revenue and profit are concentrated and recommend practical next steps.

## Tools
- Python
- pandas
- matplotlib
- Microsoft Word (report documentation)

## Files
- `ecommerce_sales_sample.csv` — 300 sample orders
- `analysis.py` — reproducible analysis and chart generation
- `Analytics_Report_Insights.docx` — report for submission
- `charts/` — generated charts

## How to run
1. Install Python 3.10+.
2. Open a terminal in this folder.
3. Install dependencies: `pip install pandas matplotlib`
4. Run: `python analysis.py`
